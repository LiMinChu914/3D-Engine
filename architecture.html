    06 / FRAME LIFECYCLE

    一幀畫面如何產生

    1. 01
      LOAD

      loadObj() / loadGltf() 非同步取得模型與材質。

    2. 02
      BUILD

      建立 Entity，掛載 Transform 與 MeshRenderer。

    3. 03
      COMPOSE

      World 索引 Components，Camera 與 Light 也是 Entity。

    4. 04
      QUERY

      Renderer 查詢 Transform + MeshRenderer 並快取 GPU 資源。

    5. 05
      CULL

      Frustum 以 Geometry bounding sphere 排除不可見 chunk。

    6. 06
      DRAW

      GLSL 計算座標、光照、波浪與距離霧，輸出至 Canvas。

    07 / ARCHITECTURE NOTE

    目前有兩條渲染路徑

    Renderer/Renderer.js 是展示網站正在使用的 3D 路徑；lib/screen/ 的 GLScreen 與 Shaders 則是早期的 2D polygon 實驗。兩者目前沒有共用資源與介面，後續應刪除舊路徑或整併成同一套抽象。
